# Bestie Check SM (بيستي تشيك SM)

منصة اجتماعية وتفاعلية ممتعة لاختبارات الصداقة، تتيح للمستخدم إنشاء اختبار شخصي عن نفسه يتكون من 20 سؤالاً، ومشاركته مع أصدقائه لاكتشاف مدى معرفتهم به من خلال إجاباتهم ودرجاتهم وترتيبهم في لوحة المتصدرين.

## 🎨 الهوية البصرية والتصميم
- **أسلوب كرتوني لطيف:** خلفيات سماوية زرقاء، بطاقات بيضاء ناعمة بحواف مستديرة، وتأثيرات أبعاد ثلاثية ناعمة للأزرار.
- **شخصيات أصلية:** دببة وحيوانات كرتونية بخدود وردية وابتسامات لطيفة.
- **بطاقات الأسئلة:** تصميم ورقة دفتر مخططة ومقسمة بأسلوب كرتوني جذاب.
- **شاشة افتتاحية:** شاشة ترحيبية لمدة ثانيتين بشعار المنصة، حقوق التطوير، مؤثر صوتي ترحيبي، وزر لكتم أو تشغيل الصوت.
- **نظام صوتي كامل:** مؤثرات تفاعلية لطيفة (أصوات نقر، انتقال، نجاح، واحتفال) مبنية بالكامل باستخدام Web Audio API.

---

## 🚀 التقنيات المستخدمة
- **الواجهة الأمامية (Frontend):** React 19 مع TypeScript و Tailwind CSS.
- **الخادم الخلفي (Backend):** Node.js و Express API آمن.
- **قاعدة البيانات (Database):** SQLite علائقية متكاملة عبر `sql.js` (WebAssembly)، مع معاملات وجداول ومفاتيح خارجية وقيود لمنع التكرار وحفظ دائم على القرص في `data/bestie_check.sqlite`.
- **التحقق والحماية (Validation & Security):**
  - فحص وتدقيق كامل لجميع المدخلات باستخدام مكتبة `Zod`.
  - عدم تسريب الإجابات الصحيحة للمتصفح نهائياً أثناء لعب الصديق؛ الحساب يتم حصرياً على الخادم.
  - رموز إدارة مشفرة (SHA-256) لحماية حذف وإدارة الاختبارات.
  - منع تكرار الإجابات عبر قيود قاعدة البيانات الفريدة (Unique Constraints).
  - حماية الجلسات باستخدام معرفات تشفير عشوائية (Cryptographic Random Tokens).

## 🛠️ التثبيت والتشغيل المحلي

### 1. تثبيت الحزم:
```bash
npm install
```

### 2. التشغيل في بيئة التطوير (Development):
```bash
npm run dev
```
يعمل التطبيق على المنفذ `3000`: `http://localhost:3000`

### 3. تشغيل الاختبارات الآلية (Testing):
```bash
npm test
```

### 4. البناء للإنتاج (Production Build):
```bash
npm run build
npm start
```

## 🔒 الأمان وحماية البيانات
1. **حماية الإجابات:** خلال حل الاختبار، لا يحتوي الـ JSON المرسل للمتصفح على حقل `is_correct` إطلاقاً، وتُحسب النتيجة النهائية في قاعدة البيانات بمقارنة المعرفات فقط بعد الانتهاء.
2. **منع التكرار:** يتم تسجيل جلسة المشارك بقيد فريد يمنع إرسال إجابتين لنفس السؤال أو التلاعب بالنتيجة.
3. **صلاحيات الإدارة:** لكل اختبار رمز إدارة عشوائي يتم تخزين تجزئته التشفيرية (Hash) فقط على الخادم، ولا يمكن لأي شخص حذف الاختبار أو استعراض نتائجه الخاصة بدون الرمز الصحيح.
